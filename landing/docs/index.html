Get started in minutes.

Alacrán runs on your own Mac or Linux machine. Here’s what you need installed and what the first run looks like. Fuller documentation is on the way.

Requirements

  • macOS 12+ or a Debian/Ubuntu-based Linux
  • Node.js installed
  • Claude Code CLI · uses your own Claude subscription
  • gog (Google CLI) · optional, only for Gmail & Calendar

Alacrán checks for all of this on first launch and walks you through anything that’s missing. Claude Code is the one it checks for, since it’s the default; you can point any individual workspace at OpenAI’s Codex CLI, Google’s Antigravity CLI, or Aider afterward instead.

Your first run

1 · Install and open

Download the app and open it. It starts up locally and opens in your browser.

2 · Set up a workspace

Build your first one from the starter template in a single click.

3 · Connect your AI

Point it at your own Claude, ChatGPT, or open-source model, then link whichever tools you use.

4 · Run something

Kick off a job, then approve the change before a single file is written.

Set it up once this afternoon. Every week after that, the routine work is already done by the time you sit down.
