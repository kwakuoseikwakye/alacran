The honest version

So what’s the catch?

There isn’t one, but there are two things worth being straight about.

You still pay for the AI. Alacrán drives a coding-agent CLI — Claude Code by default — and whatever that provider charges you is between you and them. If you point it at a local model, that cost is zero.

It’s maintained by one person. Issues and pull requests are read and genuinely welcome, but there’s no support SLA. If you need this to work a particular way, the source is right there and the licence lets you change it.

Stop explaining yourself to a blank chat box.

Set it up once this afternoon. Every week after that, the routine work is already done by the time you sit down.
