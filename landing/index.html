Requirements

Built for people comfortable installing a command-line tool. For v1 you'll need:

  • macOS 12 or later
  • Node.js installed
  • The Claude Code CLI (bring your own Claude subscription)
  • The gog Google CLI, if you want to connect Gmail / Calendar

The app detects these on first launch and guides you through anything that's missing.
