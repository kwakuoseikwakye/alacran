# state/

Generated output. **Everything here is disposable** — delete it and it comes
back next time something regenerates it.

Ships empty. `.gitignore` keeps its contents untracked and this README
tracked, so the folder survives a clone without carrying stale data.

If you find yourself hand-editing a file in here, it's in the wrong place: a
fact belongs in `definitions/`, working material in `notes/`.
