# notes/

Working material. Unlike `definitions/`, nothing here is authoritative — this
is where thinking happens before it becomes a fact or a decision.

| Folder | For |
| --- | --- |
| `inbox/` | Anything not yet sorted. Drop it here and move on. |
| `clients/` | One file per client. |
| `market/` | Competitors, pricing observations, what's changing outside. |
| `sops/` | How recurring work actually gets done. |
| `company/` | Generated summaries — `digests/`, `email-checks/`, `triage/`. |

## Rules

- **`inbox/` is allowed to be a mess.** That's its job. Sort it when you have
  a reason to, not on a schedule.
- **A note can propose a change to `definitions/`; it can't be the change.**
  Move it there deliberately.
- **Don't rewrite someone else's note to agree with you.** Add yours next to
  it and date both.
- `company/` holds command output. Safe to delete a file; it can be
  regenerated.
