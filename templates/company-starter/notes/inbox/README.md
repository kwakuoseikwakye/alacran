# notes/inbox/

Unsorted notes. Anything you don't want to lose and don't want to classify
right now.

No naming convention, no required structure. A date prefix helps
(`2026-08-12-<whatever>.md`) but nothing enforces it.

When a note here turns out to matter, move it: to `notes/clients/` or
`notes/market/` or `notes/sops/` if it's still working material, to
`definitions/` if it's become a fact, or to `docs/decisions/` if a call got
made. Deleting it once it's moved is correct — the record lives where it
landed.
