# docs/retros/

One file per retrospective: `YYYY-MM-DD-retro.md`. Written by `/retro`.

A retro records what was attempted, what actually happened, what it cost, and
**one** change to make next time. One, not a list — a list of five
improvements is a list of zero improvements.

Retros describe situations, not people. If the same situation shows up in
three retros, that's a signal to change something in `definitions/`, and
that change is its own `/decision`.
