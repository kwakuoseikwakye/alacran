# Website assets and where they came from

Provenance for every shipping raster and font under `landing/`. Update this file when one changes.

| File | Origin |
|---|---|
| `logo.png`, `logo-sm.png`, `favicon.png` | The desktop app's red scorpion. Generated by `scripts/generate-logo.py` from the owner-supplied artwork `landing/scorpion.png` (a JPEG with no alpha). Never edit by hand; change the script and rerun. |
| `mark-white.png` | Derived on 2026-10-15 from `logo.png`: same alpha channel, every pixel set to white. Used on the hero's red memory slab and the closing call to action. |
| `screens/*.webp` | Real captures of the Alacrán app. Every capture comes from a throwaway example company and is labelled "Example company · Sample data"; none shows a real workspace. The four `tour-*` captures do not exist yet, so the tour runs on interim shots of `office-dark`, `approvals` and `memory`. `*-detail.webp` are crops cut by `build-site.py`. |
| `og.png` | Drawn by `landing/build-og.py` from `logo.png`, `screens/home-1200.webp` and the Onest font. Rerun it after a headline or palette change. |
| `fonts/onest.woff2`, `fonts/jetbrainsmono.woff2` | Onest and JetBrains Mono variable fonts (latin subset), SIL Open Font License 1.1 (texts beside the files in `landing/fonts/`), taken on 2026-10-15 from the npm packages `@fontsource-variable/onest@5.1.0` and `@fontsource-variable/jetbrains-mono@5.1.0` (`files/*-latin-wght-normal.woff2`). Self-hosted; nothing loads from a font CDN. They replaced Geist and Geist Mono the same day. |
| `brands.js` | Official Simple Icons path data (CC0), generated by `scripts/generate-brand-icons.mjs`. |

The Buy Me a Coffee widget is the one third-party script on the site. It loads from `cdnjs.buymeacoffee.com` with page id `alacran`, exactly as the owner supplied it.
