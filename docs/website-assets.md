# Website assets and where they came from

Provenance for every shipping raster and font under `landing/`. Update this file when one changes.

| File | Origin |
|---|---|
| `logo.png`, `favicon.png` | The desktop app's red scorpion. Generated by `scripts/generate-logo.py` from the owner-supplied artwork `landing/scorpion.png` (a JPEG with no alpha). Never edit by hand; change the script and rerun. |
| `favicon-32.png`, `apple-touch-icon.png` | Browser tab icon (32x32, transparent) and iPhone home-screen icon (180x180, opaque on the site background `#f4f2ee`). Both are cut from the committed `logo.png` by `python3 scripts/generate-logo.py --web-icons`, which writes only these two files. A full run of the script also rewrites them. |
| `logo-sm.png` | A 92x96 scorpion image from the initial public release. No page links to it and `scripts/generate-logo.py` does not write it; only the HTTP test requests it. How it was made is not recorded: `<<TODO>>` owner to confirm, or delete it with its test route. |
| `mark-white.png` | Derived on 2026-10-15 from `logo.png`: same alpha channel, every pixel set to white. Used on the hero's red memory slab and the closing call to action. |
| `screens/*.webp` | Real captures of the Alacrán app. Every capture comes from a throwaway example company and is labelled "Example company · Sample data"; none shows a real workspace. The four `tour-*` captures do not exist yet, so the tour runs on interim shots of `office-dark`, `approvals` and `memory`. `*-detail.webp` are crops cut by `build-site.py`. |
| `og.png` | The 1200x630 link-preview card (about 103 KB), drawn by `landing/build-og.py` from `logo.png`, `screens/home-1200.webp` and the Onest font, with no network use. Every page's `og:image`, `og:image:secure_url` and `twitter:image` point at it with an absolute URL. Rerun the script, and commit the new PNG, only after a headline, benefit-line, Home screenshot or palette change; a rerun with none of those reproduces the committed bytes. |
| `fonts/onest.woff2`, `fonts/jetbrainsmono.woff2` | Onest and JetBrains Mono variable fonts (latin subset), SIL Open Font License 1.1 (texts beside the files in `landing/fonts/`), taken on 2026-10-15 from the npm packages `@fontsource-variable/onest@5.1.0` and `@fontsource-variable/jetbrains-mono@5.1.0` (`files/*-latin-wght-normal.woff2`). Self-hosted; nothing loads from a font CDN. They replaced Geist and Geist Mono the same day. |
| `brands.js` | Official Simple Icons path data (CC0), generated by `scripts/generate-brand-icons.mjs`. `build-site.py` reads its ids at build time, so a vendor mark that is not in it fails the build. Slack, OpenAI (so Codex), Canva, Lovable, DocuSign and LinkedIn have no available mark and are named in text only. |

The Buy Me a Coffee widget is the one third-party script on the site. It loads from `cdnjs.buymeacoffee.com` with page id `alacran`, exactly as the owner supplied it.
